# BIXTONE FREE - Engine Musik Gratis Selamanya
Versi GitHub Pages - 3 Menit Full, Bukan Gimik

## Durasi
- Lirik: Unlimited (1000 token = 3 menit)
- Musik: 3 menit 20 detik per generate (max_new_tokens: 1500)
- Bisa sambung jadi 6 menit

## Gimik atau tidak?
TIDAK. Full song Intro-Verse-Chorus-Outro, bukan loop 30 detik.

## Biaya
- Rp 0 selamanya
- OpenRouter FREE: 200 lagu/hari
- HuggingFace FREE: 1000 lagu/hari

## Cara Deploy di GitHub Pages (cuma HP)
1. Buat repo baru `bixtone-free`
2. Upload `index.html`
3. GitHub > Settings > Pages > Branch: main > Save
4. Buka link: `https://username.github.io/bixtone-free/`
5. Masukkan 2 API Key FREE, langsung generate.

## API Key FREE
- OpenRouter: https://openrouter.ai/keys
- HuggingFace: https://huggingface.co/settings/tokens
